Service Layer

The service layer provides core functionality for authentication, FHIR API communication, and caching.

AuthService

Location: src/services/auth.service.ts

Handles OAuth 2.0 client credentials authentication with automatic token caching and refresh.

class AuthService {
  - cache: NodeCache
  - CACHE_KEY: string = 'access_token'
  
  + async getAccessToken(): Promise<string>
  - async requestNewToken(): Promise<TokenResponse>
  + clearTokenCache(): void
  + isTokenCached(): boolean
  + getTokenInfo(): { cached: boolean; ttl?: number }
}
getAccessToken(): Promise<string>

Retrieves a valid access token, using cache if available and valid. Automatically requests a new token if cache is empty or expired.

Returns: Promise<string> - OAuth 2.0 access token
requestNewToken(): Promise<TokenResponse>

Private method that requests a new access token from the OAuth server using client credentials flow.

Request: POST to token endpoint with:
- grant_type: 'client_credentials'
- client_id: from environment
- client_secret: from environment
- scope: 'system/*.read'
Returns: TokenResponse with access_token, expires_in, token_type

FHIRService

Location: src/services/fhir.service.ts

Provides FHIR API client functionality with search, get resource, and pagination support.

class FHIRService {
  - authService: AuthService
  
  + async search<T>(
      resourceType: string,
      params: FHIRSearchParams,
      pageSize: number
    ): Promise<FHIRSearchResult<T>>
  + async getResource<T>(
      resourceType: string,
      id: string
    ): Promise<T>
  + async getNextPage<T>(
      nextUrl: string
    ): Promise<FHIRSearchResult<T>>
  + async getCapabilities(): Promise<any>
  - buildSearchParams(): Record<string, string>
  - parseSearchResult<T>(): FHIRSearchResult<T>
  - handleFHIRError(): Error
}
search<T>(resourceType, params, pageSize)

Search for FHIR resources with pagination support. Automatically includes authentication token.

Parameters:
- resourceType: string (e.g., 'Patient', 'Appointment')
- params: FHIRSearchParams - Search parameters object
- pageSize: number - Maximum results per page (default: 20)
Returns: FHIRSearchResult<T> with resources, total, hasMore, nextUrl
getResource<T>(resourceType, id)

Retrieve a specific FHIR resource by ID.

Parameters:
- resourceType: string - Resource type
- id: string - Resource ID
Returns: Promise<T> - The requested FHIR resource

Utility Layer

FHIRParser

Location: src/utils/fhir-parser.ts

Converts FHIR resources into structured, AI-friendly formats.

class FHIRParser {
  + static parsePatient(patient: FHIRResource): ParsedPatient
  + static parseAppointment(appointment: FHIRResource): ParsedAppointment
  + static parseMedication(medication: FHIRResource): ParsedMedication
  + static parsePractitioner(practitioner: FHIRResource): ParsedPractitioner
  + static parseCondition(condition: FHIRResource): ParsedCondition
  + static parseAllergyIntolerance(allergy: FHIRResource): ParsedAllergy
  + static parseObservation(observation: FHIRResource): ParsedObservation
  + static parseProcedure(procedure: FHIRResource): ParsedProcedure
  + static parseCoverage(coverage: FHIRResource): ParsedCoverage
}

Parsers extract and normalize key fields from FHIR resources:

  • Patient: name, birthDate, gender, phone, email, address, MRN
  • Appointment: patient, practitioner, location, start, end, status
  • Medication: medication name, status, intent, dosage, prescriber
  • Condition: code, display, status, onset date, severity
  • Allergy: substance, status, severity, onset date

ErrorHandler

Location: src/utils/error-handler.ts

Centralized error handling with classification and formatting.

class ErrorHandler {
  + static createValidationError(message: string): FHIRMCPError
  + static createAuthenticationError(message: string): FHIRMCPError
  + static createNotFoundError(message: string): FHIRMCPError
  + static createPermissionError(message: string): FHIRMCPError
  + static handleUnknownError(error: any): FHIRMCPError
  + static logError(error: FHIRMCPError, context: string): void
}

Error types:

  • VALIDATION_ERROR: Invalid input parameters
  • AUTHENTICATION_ERROR: OAuth token issues
  • NOT_FOUND_ERROR: Resource not found
  • PERMISSION_ERROR: Insufficient permissions (403)
  • FHIR_API_ERROR: FHIR API errors
  • NETWORK_ERROR: Network connectivity issues
  • UNKNOWN_ERROR: Unexpected errors

MCP Server Entry Point

Location: src/index.ts

The main entry point that initializes the MCP server and handles tool dispatch.

class VeradigmFHIRMCPServer { - server: Server - authService: AuthService - fhirService: FHIRService - patientTools: PatientTools - appointmentTools: AppointmentTools - medicationTools: MedicationTools - providerTools: ProviderTools - clinicalTools: ClinicalTools + constructor() - setupHandlers(): void + async start(): Promise<void> }

Request Handlers

  • ListToolsRequest: Returns all available MCP tools (20+ tools)
  • CallToolRequest: Routes tool calls to appropriate tool handler

Tool Dispatch

Tools are dispatched based on tool name:

  • Patient tools: search_patient, get_patient_details, verify_patient_identity
  • Appointment tools: get_upcoming_appointments, get_appointment_details, etc.
  • Medication tools: get_patient_medications, get_medication_requests, etc.
  • Provider tools: search_providers, get_provider_details, etc.
  • Clinical tools: get_patient_conditions, get_allergies, etc.
