Authentication Flow

OAuth 2.0 Client Credentials flow with token caching:

Authentication Steps

  1. Token Request: AuthService requests access token from OAuth server using client credentials
  2. Token Response: OAuth server validates credentials and returns access token with expiration
  3. Token Caching: Token is cached in NodeCache with TTL matching token expiration
  4. FHIR Request: FHIRService uses cached token in Authorization header
  5. Token Refresh: If token expires or is missing, new token is automatically requested
