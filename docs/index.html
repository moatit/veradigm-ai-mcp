📋 Overview

The Veradigm FHIR MCP Server is a Model Context Protocol 2.0 server that provides read-only access to Veradigm's FHIR R4 API. It enables AI voice agents to interact with healthcare data through a standardized interface.

🔐 Secure Authentication

OAuth 2.0 client credentials flow with automatic token caching and refresh

🏥 FHIR R4 Compliant

Full support for FHIR Release 4 (v4.0.1) standard resources and operations

🤖 AI Voice Agent Ready

Optimized for integration with RetellAI and other voice AI platforms

🐳 Containerized

Docker support with multi-stage builds for production deployment

📊 20+ MCP Tools

Comprehensive set of read-only operations for patient, appointment, medication, and clinical data

⚡ High Performance

Token caching, pagination support, and optimized response times

🚀 Quick Start

Prerequisites

  • Node.js 18+
  • Docker (optional)
  • Veradigm Developer Account with FHIR API access

Installation

npm install
npm run build
npm start

Docker

docker-compose up --build
