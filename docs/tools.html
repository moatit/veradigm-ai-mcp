🔧 MCP Tools Reference

Complete reference for all 21 MCP tools available in the Veradigm FHIR MCP Server

Tools Overview

The MCP server provides 21 read-only tools organized into 5 categories for healthcare data access.

👤

Patient Tools

3 tools

search_patient

Search for patients by various criteria including name, date of birth, phone, email, or MRN.

Parameters

name stringoptional
firstName stringoptional
lastName stringoptional
birthDate string (YYYY-MM-DD)optional
gender stringoptional
phone stringoptional
email stringoptional
mrn stringoptional
limit numberoptional

get_patient_details

Get detailed information for a specific patient by their FHIR resource ID.

Parameters

patientId stringrequired

verify_patient_identity

Verify patient identity by matching provided information against patient records with match scoring.

Parameters

firstName stringoptional
lastName stringoptional
birthDate stringoptional
phone stringoptional
email stringoptional
mrn stringoptional
